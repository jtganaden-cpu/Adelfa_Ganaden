
# Finding the Hypotenuse of a Right Triangle Using the Math Library

## Description

This program calculates the hypotenuse of a right triangle. 

## How to Run

1. Open the program file in VS Code, Replit, or Google Colab.
2. Run the program.
3. Enter the values of a (side a of the triangle) and b (side b of the triangle)
4. Check the hypotenuse length displayed on the screen

## Input Needed

- a 
- b

## Sample Output

Enter length for side a: 3

Enter length for side b: 7

The hypotenuse is 7.62
